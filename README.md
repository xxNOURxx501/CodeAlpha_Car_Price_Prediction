## Project Overview

This project predicts used-car selling prices from vehicle characteristics using supervised regression. The supplied `car data.csv` file contains 301 records and 9 columns.

## Objectives

- Inspect and clean the supplied dataset.
- Explore the relationship between car characteristics and selling price.
- Engineer vehicle age from the manufacturing year.
- Preprocess numeric and categorical variables using Scikit-learn Pipelines.
- Compare Linear Regression and Random Forest regression.
- Evaluate performance on unseen test data and demonstrate a sample prediction.

## Dataset

The supplied CSV is stored at `dataset/car data.csv`.

- Original size: 301 rows × 9 columns.
- Features include car name, year, selling price, present price, driven kilometres, fuel type, selling type, transmission, and owner count.
- Target: `Selling_Price`.
- Missing values: none found during inspection.
- Exact duplicate records: 2; removed during cleaning, leaving 299 records.

The dataset's original price units are preserved. No currency conversion is applied. The notebook excludes `Car_Name` from the model because the 98 distinct model names create a high-cardinality categorical feature for this small dataset. It derives `Car_Age` from `Year` and then excludes the original year field.

## Workflow

1. Load and inspect the supplied CSV.
2. Review data types, descriptive statistics, missing values, and duplicates.
3. Remove exact duplicate rows and normalize text whitespace.
4. Explore selling-price distribution and relationships with present price, vehicle age, fuel type, and numeric features.
5. Engineer `Car_Age`.
6. Split the data into training and test sets.
7. Apply median imputation, scaling, and one-hot encoding through a `ColumnTransformer` inside each model Pipeline.
8. Train Linear Regression and Random Forest models.
9. Compare MAE, RMSE, and R² on the held-out test set; calculate training-only cross-validation R² for Random Forest.
10. Demonstrate a prediction for a sample car.

## Model Evaluation

The notebook calculates the actual metrics during execution and displays a comparison table for Linear Regression and Random Forest. The model is selected using the lower mean MAE from cross-validation on training data only. The held-out test set is reserved for final evaluation.

Metrics:
- **MAE:** average absolute prediction error, in the target's original units.
- **RMSE:** square-root mean squared error, penalizing larger errors more strongly.
- **R²:** proportion of target variance explained by the model.

The test metrics are intentionally generated by the notebook rather than hardcoded in this README, so the notebook remains the source of truth if the dataset or split changes.

## Limitations and Future Improvements

- The dataset is small and may not represent current market conditions.
- Location, accident history, service records, and detailed trim/variant information are not available.
- Model names could be mapped to verified manufacturers to add brand-level information.
- A larger and more recent dataset would support stronger generalization testing.
- Predictions are estimates, not guaranteed market prices.
